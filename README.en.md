## Why this hub

- **Read-only Home** — CPU · RAM · GPU · disks, zero mutators
- **ConfirmGate** on every destructive action
- **FR | EN** · optional support · About (Terms / Privacy / Legal notice / Notices)
- Clear local paths for manual uninstall
